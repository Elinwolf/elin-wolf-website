# Elin Wolf Violin Website

A responsive luxury violinist website built with plain HTML, CSS and JavaScript.

## Before publishing

1. In `script.js`, replace `YOUR_EMAIL_HERE` with your booking email.
2. Replace the portrait placeholder with your best vertical performance image.
3. Replace the three sample testimonials with verified client reviews.
4. Add a real Open Graph image at `images/og-cover.jpg`, or update the metadata path.
5. Confirm your final domain and update canonical, Open Graph, robots.txt and sitemap.xml URLs.
6. Connect the inquiry form to HoneyBook, Formspree, Dubsado or your preferred CRM if you do not want mailto behavior.

## Preview locally

Open `index.html` in a web browser.

For a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publishing options

This static site can be published on Netlify, Vercel, GitHub Pages, Squarespace Developer Mode, or transferred into Wix/Showit/WordPress.
